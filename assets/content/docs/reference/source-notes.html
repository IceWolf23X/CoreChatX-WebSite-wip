Documentation content#

Each wiki article has its own HTML file under assets/content/docs/. Titles, categories and article order are maintained in assets/js/data/docs-content.js. Run node tools/build-docs-bundle.mjs . after editing article HTML to update the offline bundle used by the wiki, search and full reference.

Configuration examples come from the allow-listed public defaults in synced-configs/ and the generated JavaScript bundle. The Velocity advancement configuration is a separately maintained runtime template. Match the examples and feature descriptions to the CoreChatX build you install.

External references#

Advancement options, endpoint defaults, backend credential rules and safety notices are described under Paper config.yml and velocity-advancements.properties. Obtain the complete matching setup guide before enabling synchronization.

The advancement setup guide is an external reference requiring an internet connection. External pages are not bundled with the wiki.

Configuration and compatibility notes#

Use the detailed channels.yml example for mention gates: from-minecraft, from-discord and from-telegram are separate settings. Verify the Java and server-version requirements for your exact deployment.

Offline behavior#

Wiki navigation, search, highlighting, code copying and theme switching use bundled assets. The Releases page requests public GitHub metadata when opened and can use cached or bundled metadata offline. JAR downloads and external project links require an internet connection.
